# Circular-Buffer-in-C
This is a circular buffer but made in C. It accepts numbers from 10 to 200 at steps of 10 and pushes them into the buffer, when forced to overwrite it pops out the data in its path and overwrites it with the new data. At the end all the data gets popped out.
